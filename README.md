# Prakash Kumar — Developer Portfolio

A responsive, single-file portfolio built with HTML, CSS, and vanilla JavaScript. It is designed for GitHub Pages and requires no build step.

## Quick start
1. Open `index.html` in a browser to preview.
2. Replace `YOUR_EMAIL@example.com` and the LinkedIn URL with your actual links.
3. Review career dates, titles, skills, and project summaries. The project cards are illustrative summaries and should be replaced with details you can verify.
4. Optionally add a `resume.pdf` file and add a link to it in the hero section.
5. Publish with GitHub Pages using the steps below.

## Publish with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/
2. Click **New repository**.
3. Recommended: name the repository `your-github-username.github.io` for a root portfolio URL. Choose **Public** on GitHub Free.
4. Create the repository.
5. Click **Add file → Upload files**, upload `index.html` (and any optional `resume.pdf`), then click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then click **Save**.
9. Wait for the deployment to finish. The site should be available at `https://your-github-username.github.io/`. It can take several minutes to publish.
10. For a repository named something other than `your-github-username.github.io`, the URL is generally `https://your-github-username.github.io/repository-name/`.

## Important
- GitHub Pages hosts static files. It does not run PHP/Laravel backend code. This portfolio uses only HTML/CSS/JavaScript.
- Published Pages websites are publicly accessible. Do not upload passwords, private company code, customer data, or other confidential information.
- Before publishing, verify every statement, role, date, project description, and contact link.
